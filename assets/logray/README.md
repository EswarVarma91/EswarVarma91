# Logray screenshots

Drop the image files here, then uncomment the gallery block in the root
`README.md` (under section `01 · Logray`). Nothing else needs changing.

## Naming

Use the names the README already expects:

| File | Shows |
|:--|:--|
| `01-before.png` | A screen before the UI work |
| `02-after.png` | The same screen after |
| `03-components.png` | Component library / design tokens, if you can share it |

## Before you publish

- **Check you're allowed to.** Logray's screens may belong to your employer
  or client. Internal dashboards, customer names, prices, emails and IDs
  should be redacted or replaced with sample data.
- **Crop to the app**, not your whole desktop — no browser chrome, tabs,
  bookmarks or notification popups.
- **Trim the file size**: aim for under ~300 KB per image and a width around
  900–1200 px. Large PNGs are the main reason a profile README loads slowly.
- Prefer `.png` for UI screenshots, `.webp` if you need smaller files.

If you would rather not commit the images to this repo, upload them
somewhere public (e.g. an image host or a release asset) and replace the
paths in the README with those URLs instead.
