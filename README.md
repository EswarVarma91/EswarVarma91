## Now building: SAP CPI

A study site that takes someone from zero to a professional SAP Cloud Integration
developer in ninety days: a day-by-day plan, 47 lessons, ten project dossiers, and
practice that scores itself into one readiness percentage.

- **Live:** [iamsurya.web.app](https://iamsurya.web.app)
- **Code:** [EswarVarma91/sap_cpi](https://github.com/EswarVarma91/sap_cpi)

| | |
|:-|:-|
| **What it covers** | 90-day roadmap, 10 modules, 47 lessons, 10 project dossiers, 300-question bank, 520 interview questions, 47 lesson exams, mock exams, drills, an iFlow simulator |
| **Design focus** | One consistent reading layout, honest empty/loading states, progress that is always visible, phone-to-desktop parity |
| **Stack** | Static HTML, CSS and vanilla ES modules · Vite build · Firebase Auth · Firestore · Firebase Hosting |

**What I am working on in it:** the interface itself — lesson and dashboard layouts,
the readiness panel, the exam flow, and the guest-versus-account progress model where
signing out returns the browser to a clean 0% record while the account copy stays intact.
