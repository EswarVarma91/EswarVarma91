## 🧠 How I approach UI work

| | |
|---|---|
| **🧱 Systems, not screens** | Every redesign starts with tokens, spacing and reusable components — so the next feature ships faster. |
| **✨ Motion with intent** | Transitions should explain the app, not decorate it. Fast, subtle, predictable. |
| **📱 Cross-platform by default** | One mindset, three runtimes: web, Ionic/Capacitor, native — shared logic, platform-correct feel. |
| **🔍 Details are the product** | Empty states, error states, skeletons and edge cases get designed too. |
